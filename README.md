## 📖 About

🔹 **Factorio — Module Inserter** is a powerful tool built to help you automatically fill machines with productivity, speed, or efficiency modules across your entire Factorio factory. Define module configurations and Module Inserter will deploy robots to install them in every qualifying machine.

🔸 Whether you're a seasoned professional or just getting started, **Factorio — Module Inserter** delivers a clean, intuitive experience packed with everything you need — right out of the box. ## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Mass Deployment** | Install modules into hundreds of machines simultaneously via logistics bots |
| **Config Templates** | Define module setups once and apply them to all matching machine types |
| **Upgrade Support** | Automatically swap lower-tier modules for higher-tier upgrades |
| **Selective Targeting** | Filter which machine types and areas receive module installation |
